星穹 SkyShow · 无人机派单系统（演示版）

这是给客户验收用的单文件演示程序：双击即用，不需要安装 Node、浏览器或任何环境。

两个端

  • 用户端：手机尺寸的客户下单界面（顶部左侧按钮切换），可完整走「申请 → 报价 → 签合同 → 支付 → 执行 → 完成」。
  • 管理后台：宽屏管理端，可查看派单、排期日历、订单与财务、字典配置等。

登录账号

  • 管理端：admin / admin123（管理员，全部权限）
  • 管理端：operator / operator123（操作员，受限权限）
  • 用户端：演示版已内置登录态，直接进入下单流程。

数据与隐私

  • 所有演示数据存在本机 %APPDATA%\SkyShowDemo，不上传网络；关闭程序后数据保留，再次打开还是上次的进度。
  • 想恢复出厂演示数据：关闭程序后删除 %APPDATA%\SkyShowDemo 文件夹，重新打开即可。
  • 排障日志：同目录下的 desktop.log。

常见问题

  • 首次运行 Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。这是未做数字签名的正常提示，不是病毒。
  • 双击后若已在运行，程序只会把已有窗口调到前台，不会开第二份。
  • 如果本机 8090 / 8080 端口已被别的软件占用，程序会自动换端口，无需手动处理。
